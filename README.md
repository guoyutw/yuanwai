# 園外 0.1

**園外（Yuanwai）** is a public, build-in-public AI-native solo-company experiment built from 哲瑜／嚕嚕米的 real catering experience.

This repository is the company's durable operating record—not a post-hoc tutorial. The working thesis is deliberately open: start by turning existing catering experience and inquiries into a traceable operating system, then let real evidence determine whether it becomes an AI agent, matching service, marketplace, lead-generation/service business, or another direction.

## How this repository learns

`hypothesis → build/do → real-world evidence → review → decision/pivot → durable writeback → NEXT ACTION`

Knowledge moves through `evidence → candidate → canonical`. A one-off observation is not automatically a rule, and superseded strategies remain visible.
